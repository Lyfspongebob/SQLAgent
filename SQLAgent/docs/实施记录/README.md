# 实施记录规范

本目录记录每次功能实施的设计、关键决策、改动范围、验证结果和后续事项，作为课程报告、项目总结和复盘依据。

## 文件命名

```text
YYYY-MM-DD-功能简称.md
```

同一天同一功能有多次独立实施时，可增加序号：

```text
YYYY-MM-DD-功能简称-02.md
```

## 必填内容

每份记录至少包含：

1. 背景与目标。
2. 实施前状态。
3. 方案与关键取舍。
4. 数据模型、接口或流程变化。
5. 改动文件。
6. 测试与验收结果。
7. 已知限制。
8. 后续计划。

## 记录原则

- 记录真实实现，不把计划项写成已完成项。
- 明确区分“当前实现”和“生产建议”。
- 重要安全边界、降级策略和未验证事项必须写出。
- 功能完成后补充最终验证结果，不覆盖原始设计动机。
